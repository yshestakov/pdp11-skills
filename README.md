# Skills to make LLM smarter when asking about programming for PDP-11 machines

## `macro11`

This skill has been created based on OCR copy of 
the "AA-5075A-TC PDP-11 MACRO-11 Language Reference Manual"

## `rt11-prog`

This skill is based on RT-11 5.1 document: "AA-H378C-TC RT-11 Programmers Reference Manual Jul84"


## `simh-pdp11`

This skill is based on SimH 3.9 documentation.
It contains a few helper scripts, ini files to run programs on bare-metal or under RT-11 control.

RT-11 images are not included of course due to licensing issues.
