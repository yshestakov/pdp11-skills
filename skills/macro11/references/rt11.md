# RT-11 Programming Notes for MACRO-11

This file is NOT part of the AA-5075A-TC manual (that manual is OS-neutral). It summarizes the RT-11 conventions most programs need, from the RT-11 Programmer's Reference Manual / System Macro Library. Argument details vary slightly between RT-11 versions (V3–V5.7); when exact behavior matters, say so and suggest checking the RT-11 Programmer's Reference Manual for the user's version.

## Program skeleton

```asm
        .TITLE  HELLO   Print a greeting
        .IDENT  /V01.00/
        .MCALL  .PRINT,.EXIT          ; system macros come from SYSMAC.SML

START:  .PRINT  #MSG                  ; R0 <- address, EMT 351
        .EXIT                         ; back to the keyboard monitor

MSG:    .ASCIZ  /Hello, world!/       ; 0 terminator => .PRINT adds CR/LF
        .EVEN
        .END    START                 ; START = transfer (entry) address
```

Key points:
- Every system macro used must appear in an `.MCALL` (later MACRO-11 versions also accept `.ENABL MCL` to auto-.MCALL unknown op codes from the system library; not in the 1977 manual).
- `.END START` sets the transfer address. Without it the program won't start where you expect.
- The monitor sets SP from location 42 (default 1000 octal) — the stack grows down from just below your program. Don't assume more than a few hundred words of stack unless you set it yourself.
- A `.SAV` image is absolute; the linker relocates the default program section to start at 1000 (octal).
- `.PRINT` strings: terminate with 0 (`.ASCIZ`) for CR/LF afterwards, or with byte 200 to suppress it (`.ASCII /Prompt: /<200>`).

## Building and running

Native RT-11 keyboard monitor:

```
.MACRO HELLO/LIST          ; -> HELLO.OBJ, HELLO.LST
.LINK HELLO/MAP            ; -> HELLO.SAV, HELLO.MAP
.RUN HELLO
```

Or with CSI syntax: `.R MACRO` then `*HELLO,HELLO=HELLO` (output-obj,listing=source). Multiple modules: `.LINK MAIN,SUBS`. Macro libraries other than SYSMAC.SML go on the source side: `.MACRO MYLIB.SML/M,PROG`.

On a modern host the usual path is SIMH (`pdp11` simulator) booting an RT-11 disk image, with sources copied in via a tool such as PUTR or by attaching a second disk.

The open-source cross-assembler `macro11` (github.com/Rhialto/macro11, builds with `make`) assembles on the host:

```
macro11 -rt11 -m SYSMAC.SML -o hello.obj -l hello.lst hello.mac   # RT-11 object, listing
macro11 -rt11 -p ./maclib -l - hello.mac                            # .MCALL from NAME.MAC files in ./maclib; listing to stdout
```

It needs SYSMAC.SML (copy it off an RT-11 disk) or per-macro `.MAC` files to resolve `.MCALL`s; its error messages are spelled out (`***ERROR .WORD on odd boundary`) rather than DEC's single letters. Linking for RT-11 still normally happens inside RT-11 (LINK). It is also the quickest way to syntax-check code you've written.

## Programmed requests (system macros from SYSMAC.SML)

Programmed requests are macros that expand to `EMT` instructions; many load R0 with an argument or the address of an argument block. **Assume R0 is destroyed by any programmed request** unless documented as the return value.

Terminal:
| Macro | Purpose |
| --- | --- |
| `.TTYOUT [char]` | Output one character (from R0 if no arg). Waits if the output ring is full. |
| `.TTYIN [char]` | Input one character into R0 (and to `char` if given). Normally waits for a whole line (line-buffered, echo by monitor) unless special mode is set in the JSW. |
| `.TTINR` / `.TTOUTR` | Non-waiting forms; C bit set on return if no character / ring full. |
| `.PRINT addr` | Print an ASCIZ / 200-terminated string. |
| `.GTLIN buf[,prompt]` | Read a line (up to 80 chars) into buf as ASCIZ; honours indirect command files. |
| `.RCTRLO` | Reset CTRL/O so output resumes. |

Program control:
| Macro | Purpose |
| --- | --- |
| `.EXIT` | Return to monitor. |
| `.SRESET` / `.HRESET` | Soft/hard reset of channels and I/O. |
| `.SETTOP addr` | Request memory up to addr; R0 returns actual top. |
| `.QSET addr,n` | Add I/O queue elements. |
| `.CHAIN` | Chain to another program. |
| `.SCCA area,addr` | Inhibit/intercept CTRL/C. |
| `.TRPSET area,addr` | Trap-4/10 handler. |
| `.SERR` / `.HERR` | Soft/hard error mode for file requests. |

Files (channel-based; `area` is an argument block, typically `.BLKW 10` in your program, used by the V2+ macro forms):
| Macro | Purpose |
| --- | --- |
| `.LOOKUP area,chan,dblk` | Open existing file on channel; R0 returns file size in blocks. |
| `.ENTER area,chan,dblk,len` | Create file (len blocks, 0 = half largest free, -1 = largest). |
| `.READW area,chan,buf,wcnt,blk` | Read wcnt words starting at block blk (wait). R0 returns words actually read. |
| `.WRITW area,chan,buf,wcnt,blk` | Write (wait). |
| `.READ`/`.WRITE`/`.READC`/`.WRITC` | Asynchronous / completion-routine variants; `.WAIT chan` to wait. |
| `.CLOSE chan` | Close (makes an .ENTERed file permanent). |
| `.PURGE chan` | Free a channel without making the file permanent. |
| `.DELETE area,chan,dblk` / `.RENAME area,chan,dblk` | Delete / rename. |
| `.CSIGEN devspc,defext[,cstrng]` | Parse a CSI command line AND open the files (channels 0–2 output, 3–8 input). |
| `.CSISPC outspc,defext[,cstrng]` | Parse only; returns file specs. |

A device block (dblk) is 4 words of Radix-50: device, filename (2 words), extension:

```asm
DBLK:   .RAD50  /DK /                 ; device (3 chars, pad with spaces)
        .RAD50  /MYFILE/              ; filename (6 chars)
        .RAD50  /TXT/                 ; extension
```

RT-11 blocks are 256 words (512 bytes); block numbers start at 0.

Time:
| Macro | Purpose |
| --- | --- |
| `.GTIM area,addr` | Time of day as 2 words (high, low) of clock ticks since midnight (50 or 60 Hz). |
| `.DATE` | Date word in R0 (packed: age/month/day/year bits). |
| `.TWAIT area,time` | Sleep (needs timer support; time is 2-word tick count). |
| `.MRKT area,time,crtn,id` | Schedule a completion routine. |

## File I/O pattern

```asm
        .MCALL  .LOOKUP,.READW,.CLOSE,.PRINT,.EXIT
START:  .LOOKUP #AREA,#0,#DBLK        ; channel 0
        BCS     NOFILE                ; C set => error, code in byte 52
        .READW  #AREA,#0,#BUF,#256.,#0
        BCS     RDERR
        ...
        .CLOSE  #0
        .EXIT
NOFILE: .PRINT  #NFMSG
        .EXIT
AREA:   .BLKW   10
BUF:    .BLKW   256.
DBLK:   .RAD50  /DK MYFILETXT/
NFMSG:  .ASCIZ  /?MYPROG-F-File not found/
        .EVEN
```

## Error handling

Programmed requests report failure by setting the C bit; the error code is in byte location 52 (`ERRBYT`). Test with `BCS` immediately after the request — any intervening instruction that changes C loses it. For `.READW`, hitting end-of-file is error code 0. Use `TSTB @#52` to inspect the code.

## Fixed low-memory locations (the "system communication area")

| Address (octal) | Name | Use |
| --- | --- | --- |
| 40 | — | Program start address (from `.END`) |
| 42 | — | Initial stack pointer |
| 44 | JSW | Job Status Word |
| 50 | — | Program high limit |
| 52 | ERRBYT | Error byte from programmed requests |
| 53 | USERRB | User error severity (for indirect files / exit status) |
| 54 | — | Address of RMON (resident monitor base) |

JSW bits commonly used: `10000` (TTSPC$) — terminal special mode (no line buffering, no echo, `.TTYIN` returns each char); `100` (TCBIT$) — inhibit terminal wait (`.TTYIN`/`.TTYOUT` return with C set instead of blocking); `40000` (TTLC$) — enable lower-case input (otherwise the monitor folds input to upper case); `20000` (RSTRT$) — program is re-enterable. Set bits with `BIS #10000,@#44`, and clear them before exit.

## Interrupts and device registers

Standalone or driver-level code addresses Unibus/Qbus device registers directly with absolute mode (`@#177564`) — never PC-relative. The console: receiver CSR 177560, buffer 177562; transmitter CSR 177564, buffer 177566; ready bit is 200 (bit 7). Interrupt vectors are pairs (new PC, new PS) at fixed low addresses (console RX 60, TX 64). Under RT-11 prefer the `.INTEN`/`.SYNCH` macros inside interrupt routines rather than touching the monitor's state directly.
